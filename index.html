Como circular uma função

pinMode
(13, OUTPUT)
;

pinMode é o nome da função. () é a caixa de argumentos. 13 é argumento 1. OUTPUT é argumento 2. ; finaliza a instrução.

3. Operadores e cuidados rápidos

Matemáticos

+-*/%

% é o resto da divisão.

Comparação

==!=><>=<=

== compara. = atribui.

Lógicos

&&||!

&& = E, || = OU, ! = NÃO.

Erros comuns

Esquecer ;, inverter HIGH/LOW no sensor, usar = no lugar de ==.

INPUT_PULLUP

Botão com INPUT_PULLUP fica HIGH solto e LOW pressionado. A lógica pode inverter.

Motores

Nunca ligue motor direto no pino do Arduino. Use ponte H e fonte adequada.

4. Variáveis, laços, condições e funções

Variável

Caixa de memória.

int contador = 0;
float temp = 25.5;

Condicional

if (sensor == HIGH) {
  frente();
} else {
  parar();
}

Switch case

switch (estado) {
  case 0: frente(); break;
  case 1: direita(); break;
  default: parar();
}

Laços

for (int i=0; i<5; i++) {}
while (condicao) {}
do {} while (condicao);

when não é comando básico do Arduino C++; usamos if.

Passagem

Recursão: função que chama ela mesma. Use com cuidado no Arduino. Overload: funções com o mesmo nome e parâmetros diferentes. Vetor: gaveteiro de caixinhas, como int sensores[5].
